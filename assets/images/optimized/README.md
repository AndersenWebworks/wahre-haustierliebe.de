Optimized public display derivatives.

These images are generated from the licensed local copies in `assets/images/` and used by the static build for normal page rendering. The original local source copies remain available for social-card generation, image credits and provenance.

Display derivatives are intentionally smaller than the source files. Public page images are capped around a 960 px long edge where that is enough for the layout; the header mark and public logo are separate lightweight PNG derivatives.
